Studio Glossary & Alphabetical Index

Canonical definitions of Cave Recorder terminology, Take vs. Pass disambiguation, Plain Studio Language conventions, Studio Coach, Stagebox Mixer (MY MONITOR, FULL MIXER, MIXER LOCK, SENDS ON FADERS, Virtual Soundcheck), MIDI Sync, Pre-Tape Virtual Instrument, Groovebox and Studio Sampler, Hardware Direct Monitoring, Studio Pad Surface, multi-camera video, Cave Companion mobile (Sample Studio Session and Bonjour discovery), caverec-cli and Studio Engineering Skills, and an alphabetical subject index.

This chapter defines the canonical studio terminology used across every console faceplate, timeline lane, session file, and workflow in Cave Recorder (caverec), followed by the complete Alphabetical Index of the manual.

9.1 Take vs. Pass Disambiguation (Quick Guide)#

Traditional desktop digital audio workstations use the word "Take" for both an entire song recording and an overdubbed layer on a single track, causing constant confusion during band rehearsals. Cave Recorder enforces a strict four-tier studio hierarchy where Session-level Takes and Track-level Passes are completely distinct concepts:

Project (Band / Artist Workspace, e.g., GF)
 └── Session (Rehearsal Night or Tracking Day, e.g., GF_20261020-1)
      └── Take (Complete Song Run-Through Starting at 00:00:00.000)
           └── Pass (Single-Track Stem Inside That Take: PASS 01 / OD 02)
Studio Term & Level UI Badge & Location On-Disk Pattern How It Is Created & Used
Project (Level 1: Band or venture) PROJECT modal (CMD/CTRL + O) <LibraryRoot>/<ProjectTag>/ Top-level band folder containing all Sessions plus a unified _Mixes/ folder for rapid listening and cloud sharing.
Session (Level 2: Rehearsal or studio day) Session pill in Top Deck & TAKES (CMD/CTRL + 5) <ProjectTag>/<SessionID>_<Tag>/ Defines the room's 18-channel microphone patch, strip names, bus routing, and console processing shared across all Takes recorded that day.
Take (Level 3: Complete song or jam at t = 0) < TAKE 001 > in Top Deck & TAKES CATALOG Take<NNN>_<Stamp>[_<TakeTag>]/ Created whenever you press Record (R) with OVERDUB off. Every Take starts at its own 00:00:00.000 origin and is never stacked on top of another Take.
Base Pass (Level 4A: Initial track stem) PASS 01 (BASE PASS) on strip & Pass Lane rec/*_<CC>-<Name>_Rec001_<Stamp>.wav The initial 32-bit float pre-fader mono stem captured on a record-armed channel strip when the Take was first recorded from 00:00:00.000.
Overdub Pass (Level 4B: Layered track stem) OD 02, OD 03 (OVERDUB) on strip & Pass Lane rec/*_<CC>-<Name>_Rec<MMM>-OD_<Stamp>.wav A subsequent track-level recording captured inside the currently active Take when OVERDUB (O) is latched on the Top Deck.
Pass Lanes (Track sub-lanes inside a Take) PASSES (E / SHIFT + E) in TIMELINE Stored in *_Take<NNN>_take.json Expandable vertical sub-lanes under a track displaying its PASS 01 Base Pass and OD 02..N Overdub Passes for one-click comp selection (Use PASS 01 / ★ OD 02).
Pass Lanes Are Never Called Take Lanes

In Cave Recorder, track-level overdub lanes under a channel are always called Pass Lanes (PASS 01, OD 02, OD 03) and are never called "Take Lanes", and the project and session browser modal is always labeled PROJECT and is never called a "Welcome Screen" or "Welcome Dialog". A Take (TAKE 001, TAKE 002) is always an entire multitrack song performance starting at 00:00:00.000, while a Pass is a single track's recording layer inside that Take.

9.2 Studio Glossary#

The alphabetical definitions below cover every core studio concept, signal-processing stage, console switch, and workflow term in Cave Recorder, with direct links to the chapters where each topic is covered in depth.

12-Band Parametric EQ (2:12B EQ)#

Zero-latency 12-band precision state-variable parametric equalizer (B1 through B12) available in the 8-slot processor rack of every Input Track (CH01..CH32) and Subgroup Bus (SUB 1..SUB 16). Each band provides -24.0 dB to +24.0 dB gain across 20 Hz to 20 kHz, variable Q (0.10 to 18.00), and seven selectable filter shapes: peaking Bell (BELL), Low Shelf (LSHF), High Shelf (HSHF), High-Pass Filter (HPF), Low-Pass Filter (LPF), surgical Notch (NTCH), and Spectral Tilt (TILT). See Section 5.3.

30-Minute Retroactive Capture (● RETRO / SAVE RETRO)#

Continuous background audio capture system that retains the most recent 30 minutes of live 32-bit floating-point audio across all record-armed (R) input channels in system memory whenever ● RETRO is lit in the Top Transport Deck. Clicking SAVE RETRO (or pressing SHIFT + R) flushes the rolling 30-minute memory to disk as a new numbered Session Take (Take<NNN>) so spontaneous jams played while the transport was stopped are never lost. See Section 1.1.2, Section 2.2.3, and Section 3.2.

8-Slot Processor Rack#

Multi-instance reorderable eight-slot insert processing chain (Slots 1..8) on every Input Track and Subgroup Bus. Any built-in zero-latency studio processor (2:12B EQ, 3:VCA CMP, 4:AUX SND movable send tap, Amp Rig, standalone Cabinet & IR Loader, Tape Saturation, Context-Aware Gate, De-Esser, Vocal Rider, Transient Shaper, Ladder Filter, Modulation, Micro-Pitch Doubler, Gain Utility, or Signal Repair) or third-party .clap and macOS Audio Unit (AUv3 / AUv2) plugin can be inserted in one or more slots across the same strip with independent per-slot state and telemetry. Clicking any slot opens the inline SLOT N PROCESSOR picker to swap processor types, assign an installed plugin, open a floating PLUGIN GUI window, or preserve an uninstalled plugin as a non-destructive Ghost Slot (! MISSING). Slots can be reordered live during playback by dragging their :: handle or clicking ^ / v with clickless crossfading, or bypassed individually via B. See Section 4.1, Section 5.1.3, and Section 5.7.3.

Active Comp Lane (ACTIVE COMP LANE)#

The single Pass Lane currently selected for disk playback on a track inside the active Take. Highlighted in amber-copper waveform color with a green star badge (★ PASS 01 or ★ OD 02) in WAVEFORM TIMELINE (CMD/CTRL + 2) and reflected on the channel strip's gold pass indicator badge on the Mix Console. See Section 3.4 and Section 6.2.2.

Amp Dynamic Gate (AMP DYNAMIC)#

High-gain guitar and bass variant of the Context-Aware 3-Variant Noise Gate engineered for stoner rock, doom, psychedelic rock, and tube/fuzz rigs. Combines an autocorrelation pitch periodicity detector with a spectral flatness detector so whisper-quiet -34 dBFS clean fingerpicked notes (Whisper Clean Lock) and intentional 1.5 s to 5.0 s (default 2.5 s) harmonic cabinet feedback swells (Feedback Bloom Lock) remain wide open, while 50/60 Hz hum and fuzz hiss clamp shut in 15 ms to 40 ms (default 18 ms to 22 ms) on a palm-mute stop (Palm-Mute Clamp) along a click-free S-curve with split-band HF Tame de-hissing. See Section 5.4.5.

Amp Rig & Neural Amp Capture ([CIR] / [NAM] / HEAD ON/BYP / CAP)#

Zero-latency guitar and bass amplifier, cabinet, and neural capture insert processor available in any of the 8 rack slots on Input Tracks and Subgroup Buses. Operates in either [CIR] Circuit Mode (modeling 8 vacuum-tube preamp and power-amp topologies with 2x / 4x anti-aliasing oversampling) or [NAM] Neural Capture Mode (running open .nam neural amplifier models alongside 8 modeled speaker cabinets and custom .wav/.nam linear impulse responses), with independent HEAD ON/BYP and CAB BYP switches for pairing an amplifier head with downstream stereo effects and a standalone Cabinet & IR Loader slot. Includes a guided 3-step Hardware Amp & Pedal Capture Wizard (CAP) supporting three training quality modes (Standard 150 training passes, Mastering up to 1,000 training passes with held-out validation checkpointing, adaptive step-size refinement, automatic convergence early stopping, and interactive STOP & KEEP BEST, and Turbo 60 training passes), live training and validation ESR metering (STUDIO < 1% ESR), and automatic replication into <SessionFolder>/models/ and <TakeFolder>/models/ for portable cloud sync. See Section 5.4.6.

Analog Bass Voice (ANALOG BASS / BAS)#

Fifth circuit archetype in Cave Recorder's native Virtual Analog Drum Machine & Melodic Groove Sequencer (Analog Violet badge BAS, BASS archetype keycap). Pairs an oversampled band-limited sawtooth-to-variable-width-pulse VCO and phase-locked -1 oct flip-flop sub / dual-VCO beat blend with a unified 4-pole filter morphing smoothly from an uncompensated transistor ladder (with a 24 Hz pedal-bass sub-coupling bump) to a passband-compensated OTA filter, pre-filter drive with VCA feedback, asymmetric post-filter multi-drive, and analog accent coupling. Exposes a contextual Bass Voice Setup Strip (ROOT, FINE ±100 ct, GLIDE 0..500 ms, G: SLIDE / ALWAYS, ENV: RETRG / LEGTO / GATE, and MIDI: CHRM / PAD chromatic keyboard routing), melodic [2D | NOTE | VEL] step-grid gestures with violet Tie Bridge Bars, Storage-CRT XY reticles (CUTOFF × RESONANCE and ENV MOD × DRIVE), and curated factory presets in ACID & FUNK (ACID SQUELCH), STUDIO ANALOG, and SOUL POCKET (FUNK POCKET). See Section 5.9.2.

Analog VCA Compressor (3:VCA CMP)#

Zero-latency voltage-controlled amplifier dynamics processor included in every Input Track and Subgroup Bus 8-slot rack. Provides adjustable Threshold (-60.0 dB to 0.0 dB), Ratio (1.0:1 to 20.0:1 with 2:1, 4:1, 8:1, and 20:1 presets), Attack (0.1 ms to 100.0 ms), Release (10.0 ms to 1000.0 ms), Makeup Gain (0.0 dB to +24.0 dB), a 90 Hz Sidechain High-Pass Filter (SC HPF, shortcut H in Channel Inspector), Stereo Link (LINK), New York parallel blend (MIX 50%), and a real-time Gain Reduction (GR) trace. See Section 5.4.

Async Job Status Bar (⟳ Job % ✕)#

Top-Deck background task progress and cancellation pill automatically shown whenever an offline Master BOUNCE, Take Export…, Print conversion, Take split, timeline audio surgery ([REPAIR CLIPPING], [SMOOTH OVER ARTIFACT]), Studio Sampler bank load or bounce, Plugin RESCAN, Cloud upload/download, or neural amp capture runs asynchronously off the 60 Hz interface thread. Protected by automatic session-switch safety guards and transactional rollback on disk or network interruption. Click ✕ to cancel a running job cleanly without disturbing audio playback. See Section 1.3.2.

Audio Settings Modal (AUDIO SETTINGS)#

Hardware configuration dialog opened via AUDIO SETTINGS in the Top Deck (CMD + , on macOS, CTRL + , on Windows and Linux). Selects the physical input and output audio interface, sample rate (44.1, 48.0, 88.2, or 96.0 kHz), hardware buffer size (32 to 2048 frames), checks macOS Microphone permission status, runs automated hardware impulse loopback latency calibration (Measure Latency), displays Dual-Screen Pad Controller USB diagnostics, and provides one-click installation of caverec-cli and the 6 embedded Studio Engineering Skills. See Section 2.2 and Section 2.3.

Audio Unit (AUv2 & AUv3 on macOS)#

Native macOS audio effect ('aufx'), music effect ('aumf'), and Music Device instrument ('aumu') plugins instantiated out-of-process by default for crash and sandbox isolation. In the Mac App Store edition, Audio Units are the exclusive third-party plugin format (PLUGINS hides .clap controls), while direct downloads from caverec.app host both .clap and Audio Unit plugins. See Section 2.1.4 and Section 5.7.

Aux Return (AUX 1 REVERB & AUX 2 TAPE DLY .. AUX 8)#

Up to eight dedicated, solo-safe stereo effect return strips (AUX 1 through AUX 8, dynamically added via + AUX) on the right side of the Mixer feeding the Master Bus. See Section 4.3.2 and Section 5.5.

Aux Send (RVB & DLY / PRE, EQ, POST)#

Per-channel and per-subgroup stereo send level controls (-inf to +12.0 dB) feeding AUX 1 REVERB (RVB) and AUX 2 TAPE DLY (DLY), paired with a 3-way pickoff tap selector: PRE (pre-insert and pre-fader), EQ (post-EQ and pre-fader), or POST (post-fader and post-mute). See Section 4.2.3.

Base Pass (Rec001 / PASS 01)#

The initial multitrack audio stem captured on a record-armed channel strip when a Session Take is originally recorded from 00:00:00.000 with OVERDUB turned off. Stored on disk in <TakeFolder>/rec/<SessionID>_Take<NNN>_<CC>-<TrackName>_Rec001_<Stamp>.wav and displayed as PASS 01 (BASE PASS) in the channel strip header and Pass Lanes. See Section 1.2 and Section 6.2.

Bonjour Studio Discovery (_caverec._udp)#

Zero-configuration local network advertising on macOS (_caverec._udp) paired with UDP studio discovery so iOS and Android Cave Companion apps automatically list available studio workstations on the PAIR screen with zero manual IP entry. See Section 7.6.1.

Cab IR (Speaker Cabinet & Linear Impulse Response Loader)#

Standalone reorderable speaker cabinet and linear impulse response (IR) convolution rack processor (SPEAKER CABINET & IR LOADER) available in any of the 8 rack slots on Input Tracks and Subgroup Buses. Provides 8 modeled physical speaker enclosures (2x12, 4x12 25, 4x12 75, 4x12 BR, 4x12 TG, 4x12 OV, 4x12 15, and 8x10), 5 studio microphone capsule models (DYN-C, DYN-L, RBN-8, CND-L, DYN-B), continuous MIC POS and ROOM AIR, an interactive MIC HPF × MIC LPF (20..500 Hz × 2..20 kHz) 2D XY spectral contour pad, and zero-allocation time-domain FIR convolution (EXT IR, up to 2048 taps per channel) for custom mono/stereo .wav and .nam ("Linear") impulse responses managed through the three-tier (Take -> Session -> Global) [CAB IR] browser. Enables placing stereo modulation, delay, or reverb rack slots between an Amp Rig head (CAB BYP enabled) and the speaker cabinet. See Section 5.4.7.

Camera Latency Calibration (3-Second 4-Pulse Optical & Acoustic Calibration)#

Automated 3-second (34,320-sample at 48.0 kHz) optical and acoustic calibration workflow (CALIBRATE CAMERA LATENCY) supporting three desktop modes (4-Pulse Vernier Flash for external cameras, Full-Window White Flash for built-in laptop webcams facing the room, and Interactive Clapper / Hand Clap -5..+5 frame-stepping inspector) plus Cave Companion mobile direct wireless-clock Rear LED Torch 4-Pulse Calibration (FLASH SYNC ▾ drawer, calibrating rolling-shutter and encoder delay directly against wireless studio-clock timestamps with no phone speaker or microphone audio loop). Stores calibrated camera latency per hardware device in session.json so every recorded .vididx sidecar index locks visually to the 48.0 kHz audio timeline. See Section 2.5.2 and Section 7.6.3.

Cave Companion Mobile App (Android .apk & iOS .ipa)#

Native mobile studio companion application (Android API 36 / 16 KB page-size compliant caverec-v0.7.1-android-arm64.apk and iOS caverec-v0.7.1-ios-arm64.ipa) paired with the desktop workstation via ● REMOTE (CMD/CTRL + 0), zero-configuration Bonjour (_caverec._udp) Wi-Fi discovery, 6-digit MATCH CODE approval banner, QR code, or 6-digit Studio PIN. Presents 8 root tabs on tablets (PAIR | TRANSPORT | MIXER | STAGEBOX | GROOVEBOX | CAMERA | TAKES | PLAYER) and 6 root tabs on phones (PAIR | TRANSPORT | CONSOLE [MIXER | GROOVEBOX | STAGEBOX] | CAMERA | TAKES | PLAYER), plus the offline SAMPLE STUDIO SESSION (UNPAIRED SAMPLE) powered by the real studio engine (including hydrated STAGEBOX MY MONITOR and FULL MIXER exploration), universal [M][S][R] Solo Gold strip controls, Stagebox MY MONITOR vs. PIN-lockable FULL MIXER (MIXER LOCK), and Android FULL immersive taskbar mode. See Section 3.7 and Section 7.6.

Channel Strip (CHANNEL STRIP)#

Full-screen single-channel, Subgroup Bus, Aux Return, and Master Bus processing workbench (CMD + 3 on macOS, CTRL + 3 on Windows and Linux). Combines a full-height channel strip on the left with the top Signal-Flow Chain & Layout Mode Bar (SPLIT, CHAIN LANE, EQ+CMP, and HIDE TL / SHOW TL), expanded 12-band Parametric EQ and Dual-Trace RTA, VCA/FET/Opto Compressor with scrolling Gain Reduction trace, full-height Large Processor Views with 2D XY Control Pads, multi-bus output routing popover, and collapsible Mini-Timeline. See Section 5.1.2.

CLAP Plugin (1:PLUGIN & [INST])#

Third-party audio effect or Pre-Tape Virtual Instrument plugin conforming to the open CLAP (Clever Audio Plug-in, .clap) standard in direct downloads across macOS, Windows, and Linux. Audio effects host in any of the eight reorderable rack slots (1:PLUGIN..8:PLUGIN) using format-agnostic Plugin rack chrome, while CLAP instruments host at the Pre-Tape Track Input Stage ([INST]). Supports out-of-process catalog indexing in PLUGINS (CMD/CTRL + 7), native floating windows (PLUGIN GUI), non-destructive Ghost Slot recovery, automatic PDC, and LOW-LATENCY bypass. See Section 5.7.

Cloud Sync (CLOUD)#

Built-in two-way Google Drive synchronization engine for backing up Sessions and collaborating across bandmates' computers (MIXES vs. FULL transfer tiers, AUTO-FLAC ON UPLOAD, AUTO-MP3 ON UPLOAD, federated + Link Remote Project…, exclusive session write-locking with persistent READ-ONLY PREVIEW banner, and Snapshot-backed conflict merging). See Section 7.5.

Console DAW Remote ([CONSOLE DAW REMOTE])#

Second operating personality of a connected Studio Pad Surface (● CONTROLLER), framed in 4 px Console Burgundy (or Warm Preamp Copper in STAGEBOX PREAMPS). Dedicates GROUPS A..H to 8-channel strip banking (Tracks 1..32, Subgroups 1..16, Aux Returns 1..8, Master), maps MIX to 8-channel [M][S][R] Solo Gold faders and guarded 600 ms +48V Stagebox preamps, maps CHANNEL -> F1: AUX SENDS to dual-screen AUX 1..8 encoders, maps PLUG-IN to built-in Processor curves and hosted Plugin (CLAP/AU) pages, maps the 16 pads to SCENE Ranges, PAD MODE Cue Markers, and PATTERN Pass Lane comping, maps SAMPLING to CONSOLE CAPTURE & RESAMPLE, and exposes guarded Disk Take recording with the Active Take Stop Guard. See Section 4.5 and Section 8.5.3.

Control Room Monitor Bar (MONITOR: & AUTO LEVEL)#

Speaker-check and loudness-matched audition strip wired strictly downstream of the Master Bus 2-TRK PRINT live stereo Print tap and offline BOUNCE engine. Includes 4-band Linkwitz-Riley (24 dB/oct) frequency isolation buttons (SUB < 90 Hz, LOW 90-350 Hz, MID 350 Hz - 3.5 kHz, HIGH > 3.5 kHz), unity-gain MONO fold-down, equal-power STEREO DIFF ((L - R) × 0.7071) side difference solo, DIM -20 speaker attenuation, and AUTO LEVEL loudness-matched processor/rack bypass. See Section 4.3.4.

Cycle Loop (⇄)#

Master Transport mode (C or clicking ⇄ in the Top Deck) that loops playback or overdub recording continuously between the START and END boundaries of the active Take Range (R001, R003, ...). See Section 3.4 and Section 6.3.2.

Drum Bleed Gate (DRUM BLEED)#

Percussion-focused variant of the Context-Aware 3-Variant Noise Gate designed to isolate rack and floor toms from loud snare and cymbal spill. Combines a resonant fundamental sidechain filter (Q = 4.0) with one-click [LRN] pitch auto-detection (55 Hz to 350 Hz, default 110 Hz), differential snare/cymbal spill rejection (E_key - α * E_ref), 1.5 ms lookahead with < 0.25 ms attack, and an envelope-driven dynamic decay low-pass filter (20 kHz sweeping down to an adjustable 250 Hz to 800 Hz cutoff, default 380 Hz) that removes hi-hat wash during tom ring-outs. See Section 5.4.5.

Drum Stem Breakout (STEM)#

Individual voice multi-out routing option inside the native Virtual Analog Drum Machine that removes a chosen drum voice (such as Kick, Snare, or Clap) from the internal Drum Master Glue Bus by default (preventing comb filtering) and routes its stereo output directly into a dedicated Mix Console channel strip at zero added latency for independent console EQ, compression, Aux 1..8 Reverb/Delay sends, raw .wav Pass recording, and 30-minute RETRO capture. See Section 5.9.1.

Drum Studio ([DRUM STUDIO] / PAD:DRUM)#

Primary instrument operating personality of a connected Studio Pad Surface dedicated to Cave Recorder's native Virtual Analog Drum Machine, ANALOG BASS synthesizer, and STUDIO SAMPLER. Combines 16 velocity- and pressure-sensitive pads (PAD MODE, KEYBOARD chromatic and folded scales, STEP MODE bottom-to-top 64-step sequencer, NOTE REPEAT, ARP, and ALL + NOTE REPEAT Slip Beat-Repeat pads), live Storage-CRT voice oscilloscope and 8-encoder macro control, the 4-tab SAMPLING workspace (RECORD | EDIT | SLICE | ZONE, split zero-crossing zoom, live pad-tap chop, and SHIFT + SAMPLING for STEM & SYNC), CTRL ALL sweeps, GROUPS A..H Pattern Banks and Morph Slots (and 64-slice banking in SLICE-LOCK), Pattern Overdub recording (REC = [● PAT OVR] only, never touching Disk Take recording), and live Drum Sequencer Dropout/Re-Entry via bare PLAY while a multitrack Disk Take rolls. See Section 3.9 and Section 5.10.2.

Dual-Trace Spectrum Analyzer (RTA)#

High-resolution real-time acoustic spectrum analyzer displayed behind the 12-Band Parametric EQ curve in both the Mix Console Upper Well 2 and the CHANNEL INSPECTOR view. Plots the pre-EQ input spectrum (darker shaded trace) and post-EQ output spectrum (bright emerald trace) simultaneously from 20 Hz to 20 kHz. See Section 5.3.2.

Export Take (EXPORT TAKE / _Exports/)#

Multi-format external project and stem interchange workflow inside the SESSION REEL view (CMD/CTRL + 4) that packages any recorded Take into .rpp project files, .als Live Set projects, <Session version="7003"> XML session folders, .dawproject open interchange archives, .fcpxml v1.9 video timelines, or universal Broadcast Wave (bext / iXML / MIDI marker / 24-bit 48 kHz minimum-phase impulse response) bundles. Writes to <TakeFolder>/export/ and links into <ProjectTag>/_Exports/ with either zero-copy relative stem references or self-contained copied/rendered audio stems and .nam neural amplifier models. See Section 7.2.4.

Ghost Slot (! MISSING Plugin Recovery)#

Non-destructive rack or instrument placeholder activated automatically when a Session, Snapshot, or Session Template references a CLAP or Audio Unit plugin that is not currently installed on the workstation or was moved on disk. Marked in amber as ! MISSING (! <Name>) in the 8-Slot Processor Rack or Zone-2 Instrument bar, a Ghost Slot passes clean audio so the session plays cleanly while preserving the original plugin_id, plugin display name, and saved binary preset state untouched across saves until the plugin is relinked via LOCATE..., reinstalled and rescanned via RESCAN DIRECTORIES, or replaced. See Section 5.7.4.

Gridless MIDI Sync & Looper Bridge (MIDI SYNC)#

Bidirectional 24 PPQN MIDI Clock (0xF8) and Transport (Start 0xFA / Stop 0xFC) synchronization system opened via the Top-Deck SYNC: FREE / SYNC: ARM / SYNC: CNT / SYNC: LOCK pill. Locks external drum machines, hardware floor loopers, AUX 2 Stereo Delay, 4-Mode Modulation, and the native Drum Machine to an exact rational sample span derived from either a 4-Tap Count-In (TAP (T) with optional AUTO-REC ON BEAT 1 and 23 Beat-4 warmup pulses) or a Freeform Floor-Looper Capture (ARM LOOP CAPTURE / LOOP STOMP / CC 80 footswitch, muting 0xF8 between Stomp 1 and Stomp 2 so AUTO-clock loopers never warble), with beat-quantized 0.5x, 1.0x, and 2.0x rational scaling and zero cumulative drift. See Section 2.7.

Hardware Direct Monitoring (HW DIRECT MON)#

Persistent studio monitoring preference saved globally inside device_settings.json for musicians who monitor live tracking inputs through their audio interface or stagebox's zero-latency hardware mixer rather than software foldback. Activated either from the Live Monitoring Latency Warning banner (Enable Hardware Direct Monitoring) or via the HW DIRECT MON toggle inside the Top Deck Latency & PDC Transparency Breakdown popover, where it can be switched back to software DAW monitoring at any time (clearing any per-session warning dismissal watermark). See Section 2.2.2 and Section 5.7.6.

Hardware MIDI Latency Ping (PING)#

1-click calibration tool inside Section 3 of the MIDI SYNC & HARDWARE CALIBRATION modal that sends 5 timed NOTE or 0xFA STEP 1 test bursts out a selected MIDI output port (USB or DIN 5-PIN), measures the exact acoustic return onset on the chosen RETURN ADC input channel (IN 01..32), and persists the median hardware MIDI-to-ADC delay in microseconds inside device_settings.json so calibrated external synths and drum machines land sample-accurately on Beat 1 via brief silent pre-roll (<= 25 ms). See Section 2.7.3.

Input Monitor (I)#

Per-track console switch (I on channel strips, MON in Channel Inspector, shortcut SHIFT + I on the inspected track in Mix Console) that routes the live physical hardware input (IN 01..IN 18) through the channel's 8-slot processor rack and fader even while transport playback is rolling, allowing musicians to rehearse or monitor live overdubs through console EQ, compression, and reverb. See Section 4.2.4.

Input Trim (TRM)#

Digital pre-insert gain control (-24.0 dB to +24.0 dB, default 0.0 dB) located at the top of every Input Track and Subgroup Bus strip. On Input Tracks, TRM sits upstream of both the raw multitrack stem recorder (rec/) and the 8-slot processor rack so you can fine-tune preamp gain staging before stems hit disk. On Subgroup Buses, TRM gain-stages the summed multi-channel signal entering the subgroup's SUB RACK. See Section 4.1 and Section 4.2.2.

Keymap View (KEYMAP)#

Interactive keyboard shortcut reference and customization workspace (CMD + 8 on macOS, CTRL + 8 on Windows and Linux). Lists all 62 bindable studio actions across seven scopes with live substring search, interactive Reverse-Search by Shortcut (FIND BY SHORTCUT:), scope filter pills, inline key-chord capture (ASSIGN / APPLY), scope clash detection, operating-system conflict warnings (OS WARN), and automatic persistence to keymap.json. See Section 8.3.

Live Mix (A/B Live Mix & Return to Live Mix)#

Automatic working-memory safeguard that preserves your live, unsaved Mixer state the instant you click AUDITION SNAP <NNN> in TAKES (CMD/CTRL + 5), docking a persistent 28 px AUDITIONING SNAP NNN banner across all workspace tabs so you can click A/B Live Mix or press BACKSPACE (Return to Live Mix) with zero lost fader moves. See Section 7.3.2.

Live Stereo Print (2-TRK PRINT / Print001)#

Real-time 2-track post-Master-Bus stereo recording captured concurrently alongside raw pre-fader multitrack stems whenever a Take is recorded with 2-TRK PRINT enabled on the MST MASTER BUS strip. Written to <TakeFolder>/mix/<SessionID>_Take<NNN>_Print<NNN>_<Stamp>.wav with automatic Plugin Delay Compensation (PDC) latency trimming, and convertible via Export… (Convert Print to FLAC / MP3) in TAKES to lossless 24-bit .flac or 320 kbps CBR .mp3 linked into <ProjectTag>/_Mixes/. See Section 1.1.3 and Section 7.2.

Low-Latency Monitoring (LOW-LATENCY)#

Top Deck monitoring mode (LOW-LATENCY in Row 2 of the Top Deck) that temporarily bypasses high-latency lookahead CLAP and Audio Unit plugins on record-armed (R) live monitoring paths and their downstream buses during overdubbing, paired with the Live Monitoring Latency Warning banner (Enable Low-Latency Monitoring, per-session Dismiss, and globally persistent Enable Hardware Direct Monitoring). See Section 5.7.6.

Mac App Store Edition (App Sandbox)#

Sandboxed macOS distribution of Cave Recorder installed from the Mac App Store. Uses native macOS Open/Save panels with persistent App-Scoped Security-Scoped Bookmarks for external library/session folders, defaults its Library Root to ~/Library/Containers/com.caverec.daw/Data/Music/caverec, hosts isolated out-of-process Audio Units exclusively (hiding .clap controls in PLUGINS), and omits bundled external helper/CLI binaries while still accepting loopback 127.0.0.1 connections from an externally installed caverec-cli. See Section 2.1.4.

Markers & Ranges (MARKERS / M001 / R001)#

Sample-accurate timeline cue flags and bounded time spans stored per Take and managed in both TIMELINE and the dedicated MARKERS workspace (CMD/CTRL + 4). See Section 5.9.

Vocal Rider (VOCAL RIDER)#

Zero-latency automatic vocal and instrument leveler (±6.0 dB range around a selectable -36 to -6 dBFS target) driven by a speech-weighted (250 Hz to 4.0 kHz) detector and protected by a Breath & Bleed Freeze Gate (Freeze Threshold, default -48 dBFS) that holds the fader steady during vocal pauses so live drum and amplifier room bleed is never boosted before the compressor. See Section 5.3.4.

Waveform Timeline (TIMELINE)#
